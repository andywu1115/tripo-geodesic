# Tripo 3D Mesh Geodesic Pathfinding & Spatial Analysis Engine

CSE 20312 final project. Loads a mesh generated by the Tripo AI API, builds a
weighted surface graph with edges weighted by 3D Euclidean distance, and
computes shortest surface paths with a hand written MinHeap and Dijkstra.

Status: in progress. Full README to follow the course README.md guidelines.
